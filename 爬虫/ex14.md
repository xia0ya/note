# 练习十四：Base64编码图片的爬取与解码还原

本练习演示如何爬取网页中以Base64编码嵌入的图片，并进行解码还原为本地图片文件。

---

```python
# encoding: utf-8
# @Author: xia0ya
# 功能：爬取Base64编码的图片并解码还原为本地图片

import base64
import requests
from lxml import etree
import re

url = "https://spiderbuf.cn/web-scraping-practice/scraping-images-base64"
MyHeaders = {'user-agent':"Mozilla/5.0 (Linux; Android 6.0; Nexus 5 Build/MRA58N) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/137.0.0.0 Mobile Safari/537.36 Edg/137.0.0.0"}

# 获取网页源码
html = requests.get(url, headers=MyHeaders).text
# print(html)   # 可选：打印网页源码

# 解析网页内容，提取所有图片的src属性
root = etree.HTML(html)
imgs = root.xpath('//img/@src')
print(imgs)  # 打印所有图片Base64字符串
for item in imgs:
    # 去除Base64头部信息
    item = item.replace('data:image/png;base64,','')
    # 解码Base64字符串为二进制图片数据
    img_data = base64.b64decode(item)
    # 保存为本地图片文件
    with open('1.png','wb') as img:
        img.write(img_data)
```

---

## 说明
- 该代码会下载网页中以Base64编码嵌入的图片，并解码还原为本地图片。
- 需要提前安装 `requests`、`lxml` 和 `base64`（Python内置）库。
- 可根据实际需求修改图片保存路径和命名方式。
