# 练习二十五：代理服务器与链接陷阱处理

本练习演示如何在被屏蔽IP后使用代理服务器爬取内容，并识别和规避链接陷阱。

---

```python
# coding=utf-8
# 功能：使用代理服务器爬取内容，识别并规避链接陷阱

import requests
from lxml import etree
import re

base_url = 'https://spiderbuf.cn/web-scraping-practice/block-ip-proxy'

myheaders = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.164 Safari/537.36'}

proxies = {'http':'47.122.65.254:8080'}  # 代理服务器

# 获取首页内容，解析所有分页链接
html = requests.get(base_url, headers=myheaders, proxies=proxies).text
root = etree.HTML(html)
lis = root.xpath('//ul[@class="pagination"]/li/a')
pages = []
for item in lis:
    print(item.attrib['href'])
    if item.attrib['class'] != 'item trap':  # 过滤掉链接陷阱
        pages.append(item.attrib['href'])
print(pages)
i = 1
for item in pages:
    print(item)
    s = item.replace('/web-scraping-practice/block-ip-proxy','')
    print(base_url + s)
    url = base_url + s
    html = requests.get(url, headers=myheaders).text
    # 保存每页源码
    with open('./e04_%d.html' % i, 'w', encoding='utf-8') as f:
        f.write(html)
    root = etree.HTML(html)
    trs = root.xpath('//tr')
    # 保存每页表格数据
    with open('./e04_%d.txt' % i, 'w', encoding='utf-8') as f:
        for tr in trs:
            tds = tr.xpath('./td')
            s = ''
            for td in tds:
                s = s + str(td.xpath('string(.)')) + '|'
            print(s)
            if s != '':
                f.write(s + '\n')
    i += 1
```

- 该代码演示了如何使用代理服务器爬取内容，并识别和规避链接陷阱。
- 需要提前安装 `requests` 和 `lxml` 库。
- 可根据实际需求保存数据到本地文件。
