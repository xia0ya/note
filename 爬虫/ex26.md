# 练习二十六：随机CSS类名与无Element ID的网页爬取

本练习演示如何应对网页元素使用随机CSS类名、无ID的情况，直接通过结构定位提取数据。

---

```python
# coding=utf-8
# 功能：通过结构定位提取无ID、随机CSS类名网页的数据

import requests
from lxml import etree

base_url = 'https://spiderbuf.cn/web-scraping-practice/random-css-classname'

my_headers = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.164 Safari/537.36'}

# 获取网页源码
html_bytes = requests.get(base_url, headers=my_headers).content
html = html_bytes.decode()
root = etree.HTML(html)
with open('./n07.html', 'w', encoding='utf-8') as f:
    f.write(html)
# 通过结构定位提取数据
divs = root.xpath('/html/body/main/div[2]/div')
with open('./n07.txt','w',encoding='utf-8') as f:
    for div in divs:
        print(div.text)
        if div.text:
            f.write(f'{div.text}\n')
```

---

## 说明
- 该代码演示了如何通过结构定位提取无ID、随机CSS类名网页的数据。
- 需要提前安装 `requests` 和 `lxml` 库。
- 可根据实际需求保存数据到本地文件。
