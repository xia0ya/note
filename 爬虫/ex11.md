# 练习十一：无序号翻页的网页数据爬取

本练习演示如何处理没有页码序号、通过随机字符串分页的网页，自动遍历所有分页并抓取表格数据。

---

```python
# encoding: utf-8
# @Author: xia0ya
# 功能：自动识别无序号分页链接，循环爬取所有分页表格数据

import requests
from lxml import etree
import re

# 分页网页的基础URL
base_url = "https://spiderbuf.cn/web-scraping-practice/scraping-random-pagination"
MyHeaders = {'user-agent':"Mozilla/5.0 (Linux; Android 6.0; Nexus 5 Build/MRA58N) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/137.0.0.0 Mobile Safari/537.36 Edg/137.0.0.0"}

# 获取首页内容，解析所有分页链接
html = requests.get(base_url, headers=MyHeaders).text
root = etree.HTML(html)
lis = root.xpath('//ul[@class="pagination"]/li/a/@href')  # 获取所有分页的href

for item in lis:
    print(item)  # 打印分页链接
    url = 'https://spiderbuf.cn' + item  # 拼接完整数据url
    print(url)
    html = requests.get(url, headers=MyHeaders).text
    root = etree.HTML(html)
    trs = root.xpath('//tr')
    for tr in trs:
        tds = tr.xpath('./td')
        s = ''
        for td in tds:
            # 提取所有嵌套标签文本
            s = s + str(td.xpath('string(.)')) + '|'
        print(s)
```

---

## 说明
- 该代码会自动获取所有分页链接，循环爬取每一页的表格内容。
- 需要提前安装 `requests` 和 `lxml` 库。
- 可根据实际需求将数据保存到本地文件。
