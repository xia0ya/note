# 练习十八：无头浏览器的使用（Selenium）

本练习演示如何使用 Selenium 启动无头浏览器（Chrome），并自动访问网页。

---

```python
# 无头浏览器使用示例
# 需提前下载并配置好 ChromeDriver
# ChromeDriver 下载地址：https://googlechromelabs.github.io/chrome-for-testing/
# 也可参考：https://registry.npmmirror.com/binary.html?path=chromedriver/

from selenium import webdriver
from selenium.webdriver.chrome.service import Service

# 指定下载的ChromeDriver的完整路径
# 请将 driver_path 替换为你本地实际的 chromedriver.exe 路径
# 例如：driver_path = r"D:\Program Files\chromedriver\chromedriver-win64\chromedriver.exe"
driver_path = r"D:\Program Files\chromedriver\chromedriver-win64\chromedriver.exe"
service = Service(driver_path)
client = webdriver.Chrome(service=service)
# client = webdriver.Chrome()  # 如果已配置环境变量可直接用这行

client.get('https://www.baidu.com')  # 打开百度首页
print(client.title)  # 打印网页标题
client.quit()  # 关闭浏览器
```

---

## 说明
- 该代码演示了如何用 Selenium 启动 Chrome 浏览器并自动访问网页。
- 需要提前安装 `selenium` 库，并下载对应版本的 ChromeDriver。
- 可用于处理需要 JS 渲染的网页、自动化测试等场景。
