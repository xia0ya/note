# 练习十二：user-agent与referer校验反爬

本练习演示如何通过设置 user-agent 和 referer 请求头，绕过网站的反爬虫校验，抓取网页中的企业信息数据。

---

```python
# encoding: utf-8
# @Author: xia0ya
# 功能：通过设置 user-agent 和 referer 请求头，抓取网页企业信息数据

import requests
from lxml import etree

url = "https://spiderbuf.cn/web-scraping-practice/user-agent-referrer"
MyHeaders = {
    'user-agent':"Mozilla/5.0 (Linux; Android 6.0; Nexus 5 Build/MRA58N) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/137.0.0.0 Mobile Safari/537.36 Edg/137.0.0.0",
    'Referer':'https://spiderbuf.cn/web-scraping-practices/3?order=learn'
}

# 发送带请求头的请求
html = requests.get(url,headers=MyHeaders).text
# print(html)   # 可选：打印网页源码

# 解析网页内容，提取企业信息
root = etree.HTML(html)
ls = root.xpath('//div[@class ="container"]/div/div')

for item in ls:
    hnodes = item.xpath('./h2')
    s0 = hnodes[0].text  # 企业名称

    pnodes = item.xpath('./p')
    s1 = pnodes[0].text  # 排名
    s2 = pnodes[1].text  # 企业估值
    s3 = pnodes[2].text  # CEO
    s4 = pnodes[3].text  # 行业
    s = s0 + '|' + s1.replace('排名：','') + '|' + s2.replace('企业估值(亿元)：','') +'|' + \
        s3.replace('CEO：','')+ '|' + s4.replace('行业：','')
    print(s)
```

---

## 说明
- 该代码通过设置 user-agent 和 referer 请求头，绕过反爬虫校验，抓取网页中的企业信息。
- 需要提前安装 `requests` 和 `lxml` 库。
- 可根据实际需求将数据保存到本地文件。
